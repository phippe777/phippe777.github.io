## Publicación en GitHub Pages

1. **No elimines el sitio actual hasta que estés conforme con esta versión.** Guarda una copia del repositorio anterior.
2. Ejecuta `npm.cmd install` para generar `package-lock.json` y después `npm.cmd run build` para verificar que compile sin errores.
3. Sube **el contenido de esta carpeta**, incluyendo `package-lock.json` y `.github/workflows/deploy.yml`, al repositorio personal **phippe777/phippe777.github.io** (rama `main`). No subas `node_modules` ni `dist`.
4. En el repositorio ve a **Settings → Pages → Build and deployment → Source → GitHub Actions**.
5. Revisa la ejecución de **Actions → Deploy FO portfolio to GitHub Pages**. Cuando esté en verde, verifica `https://phippe777.github.io/` en computador y móvil antes de agregar la URL a la hoja de vida.

**Importante:** `npm ci` en GitHub Actions requiere `package-lock.json`. Debes generarlo con `npm.cmd install` y subirlo al repositorio. El proyecto contiene `base: '/'` para el repositorio raíz `phippe777.github.io`.
